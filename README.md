# JS - Square Eyes

Square Eyes is a simple website for browsing and “purchasing” movies. The project is built using HTML, CSS, and JavaScript, and it is hosted on GitHub Pages.

## Features

- Browse movies fetched from an external API (Noroff Square Eyes API)
- View movie details on separate pages
- Simple “buy” flow design (UI only, no real payment system)
- Responsive layout for different screen sizes
- Clean and structured user interface

## Technologies

- HTML
- CSS
- JavaScript
- REST API
- GitHub Pages (hosting)

## API
This project uses the Noroff API Square Eyes:

https://v2.api.noroff.dev/square-eyes

## Getting Started
To view the Project:
- Open the live website on GitHub Pages
- Download the project and open index.html
  
## Purpose

This project was created as part of a school assignment focusing on JavaScript, API integration, and improving layout, structure, and basic UX design.
